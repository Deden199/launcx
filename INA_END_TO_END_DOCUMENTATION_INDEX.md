## 💡 Key Information At a Glance

### Payment
```
Endpoint:    POST /api/v1/create-order
Auth:        x-api-key header
Input:       {price, buyer, merchantName="ing1", subMerchantId}
Output:      {orderId, checkoutUrl, qrPayload, totalAmount, expiredTs}
Flow:        Create → Get QR → Customer pays → Callback → PAID → Settle
Fee:         None (handled by INA)
Status:      PENDING → PAID → SETTLED
Settlement:  Automatic next day 4 PM
```

### Withdrawal
```
Endpoint:    POST /api/v1/client/dashboard/withdraw
Auth:        Authorization: Bearer TOKEN
Input:       {subMerchantId, sourceProvider="ing1", account_number, bank_code, amount...}
Output:      {refId, status}
Flow:        Request → Validate → Execute → Callback/Fallback → COMPLETED
Fee:         Your fee % + INA fee (from inquiry)
Status:      PENDING → COMPLETED/FAILED
Completion:  Minutes (via callback or 30s fallback)
```

### Settlement
```
Endpoint:    POST /api/v1/admin/settlement/run-manual
Schedule:    Daily 4 PM (automatic)
Input:       {filters: {dateFrom, dateTo, paymentMethods}}
Output:      {jobId, status, settledOrders}
Flow:        Fetch PAID → Check INA → Update SETTLED → Balance++
Fee:         None
Duration:    1-5 minutes
Notification: Telegram
```
